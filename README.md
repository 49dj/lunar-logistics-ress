# Reliability-informed robust optimisation of Earth–Moon infrastructure logistics — reproducibility package

Code, data, and figure-generation scripts for the manuscript:

> *Reliability-informed robust optimisation of Earth–Moon infrastructure logistics under launch and space-elevator disruptions* (prepared for possible submission to *Reliability Engineering & System Safety*).

This repository is intended for private sharing with the editor and reviewers after author approval and will be deposited publicly upon acceptance.

The frozen reviewer snapshot is tagged `v9-review`. Its complete clean-environment transcript is deposited at `logs/verification_final.log`.

## Integrity statement

**Every robust-optimisation number reported in the manuscript (Sections 6.1 and 7.1; Tables 8–10) is generated by `src/task2b_robust_milp.py`**, a reliability-adjusted MILP re-solve of the Task-1 deterministic baseline. An earlier exploratory robustness script that reported fixed constants instead of solver outputs has been removed from the publication path; it is not part of this repository and is not the source of any number in the manuscript. The fail-closed master verification harness (`src/run_all.py`) checks the regenerated outputs against the manuscript's reported values — including byte identity of `outputs/pareto_robust.csv`, the content of the deposited feasibility scan, and regression guards against parameter-state contamination and false-positive summaries.

## Environment

Verified with Python 3.12 and the pinned versions in `requirements.txt`
(numpy 1.26.4, scipy 1.13.1, pandas 2.3.2, matplotlib 3.10.5).
SciPy ≥ 1.9 is required for `scipy.optimize.milp` (HiGHS branch-and-bound).

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## One-command reproduction

```bash
python src/run_all.py
```

This re-solves everything and verifies the manuscript's reported values
(≈ 2–5 minutes; Task 2b itself takes ~1 second). Expected final line:

```
ALL CHECKS PASSED — code reproduces the manuscript's reported values
```

Individual analyses:

```bash
python src/task2b_robust_milp.py          # robust frontier + knee + Figure 8   (~1 s)
python src/task2b_robust_milp.py --scan   # exhaustive feasibility scan T=100-137 (~1 s)
python src/fig9_frontiers.py              # Figure 9 from the deposited CSVs
python src/task1_q1_milp.py               # deterministic baseline + §4/§7.2 figures (~2-4 min)
```

Regression tests for the verification harness:

```bash
python -m unittest discover -s tests -v
```

## For reviewers

1. Clone (or unzip) the repository.
2. Create the environment and run `python src/run_all.py` (section above).
3. The harness prints one `[PASS]`/`[FAIL]` line per manuscript claim; the reproducibility gate confirms `outputs/pareto_robust.csv` is regenerated byte-identically from the solver.
4. Questions about any specific number: the provenance map above identifies the generating script; all scripts are deterministic (fixed seeds for the sampling-based sensitivity analyses).
